# Graph Theory Algorithms

Консольное приложение на C++ для демонстрации и визуализации основных алгоритмов теории графов. Реализовано в рамках лабораторных работ по дисциплине "Теория графов".

---

## Возможности

### Генерация графов
- Генерация случайных связных графов с заданным количеством вершин
- Поддержка ориентированных и неориентированных графов
- Степени вершин генерируются по распределению Пирсона
- Проверка связности сгенерированного графа

### Матричные представления
- Матрица смежности
- Матрица весов (положительные, отрицательные, смешанные веса)
- Матрица стоимостей
- Матрица пропускных способностей

### Алгоритмы на графах

| № | Алгоритм | Описание |
|---|----------|----------|
| 1 | Центр и диаметр графа | Вычисление эксцентриситетов, радиуса, диаметра, центра и диаметральных вершин |
| 2 | Метод Шимбелла | Поиск минимальных и максимальных путей заданной длины |
| 3 | Подсчёт маршрутов | Подсчёт всех маршрутов заданной длины между вершинами (степени матрицы смежности) |
| 4 | Обход в глубину (DFS) | Итеративный обход графа с использованием стека |
| 5 | Алгоритм Дейкстры | Поиск кратчайших путей от заданной вершины во взвешенном графе |
| 6 | Алгоритм Форда-Фалкерсона | Поиск максимального потока в сети |
| 7 | Поток минимальной стоимости | Поиск потока заданной величины (2/3 от максимального) с минимальной стоимостью |
| 8 | Теорема Кирхгофа | Вычисление числа остовных деревьев через матрицу Кирхгофа |
| 9 | Алгоритм Краскала | Построение минимального остовного дерева |
| 10 | Код Прюфера | Кодирование и декодирование остовных деревьев |
| 11 | Максимальное независимое множество | Поиск максимального независимого множества вершин |
| 12 | Эйлеров цикл | Проверка на эйлеровость, модификация графа и построение эйлерова цикла (алгоритм Флери) |
| 13 | Фундаментальная система разрезов | Построение разрезов на основе остовного дерева |

- **Язык:** C++17/20
- **Стандартная библиотека:** STL (vector, queue, stack, set, priority_queue)
